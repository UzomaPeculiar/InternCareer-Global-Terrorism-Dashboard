# InternCareer-Global-Terrorism-Dashboard

## Project Overview
This project involves creating an interactive Power BI dashboard to analyze global terrorism trends using the Terrorism Database. The dashboard provides insights into attack frequencies, locations, types, weapons used, and casualty impacts over time. It enables users to explore patterns dynamically through filters and visuals. This project was completed as part of a virtual internship with InternCareer for the role of Data Scientist Intern. The goal was to build an interactive Power BI dashboard to explore and visualize terrorism patterns worldwide.

## Data Sources
- **Primary Dataset**: [Global Terrorism Database (GTD)](https://www.start.umd.edu/gtd/)  
  - Contains details such as date, location, attack type, weapons, casualties, and responsible groups.  
  - Data spans from [1970] to [2017]

## Tools Used
- **Power BI**: Dashboard creation, visualization, and interactivity.  
- **Power Query**: Data cleaning and transformation.

## Data Cleaning/Preparation
1. **Handling Missing Values**:  
   - Removed rows with incomplete critical fields
2. **Outlier Treatment**:  
   - Filtered unrealistic casualty figures 
3. **Data Type Standardization**:  
   - Converted date fields to `DateTime` format.
  
## Exploratory Data Analysis (EDA)
Key questions explored:  
1. How have attack frequencies evolved annually?    
2. Which regions are most affected?   
3. What are the most common attack types?   
4. Relationship between weapon types and casualties.
